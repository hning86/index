## 🔄 How to Update This Index

```bash
uv run fetch_repos.py > README.md
```

### 🔑 Environment Variables
The script loads environment variables from a `.env` file in the root directory. To run this script securely, bypass GitHub rate limits, and include private repositories, create a `.env` file containing your Personal Access Token:
```env
GITHUB_TOKEN=your_personal_access_token
```

> **Note**: For private repositories to be included, your Personal Access Token must have the `repo` scope (classic token) or `Contents: Read-only` and `Metadata: Read-only` permissions (fine-grained token).
